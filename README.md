🍔 Foody Zone is a modern React.js web application that allows users to explore and filter food items effortlessly. The app includes:

🧭 A stylish navigation bar with logo, search field, and menu buttons
🍱 Dynamic food cards that fetch data from a local server folder
🔍 Real-time search filter to find foods quickly
🍔 Menu button filter for category-based exploration
⚡ Built with React.js, CSS modules/styled-components, and clean UI principles

🚀 Perfect project to showcase skills in React state management, filtering logic, and front-end data handling.
